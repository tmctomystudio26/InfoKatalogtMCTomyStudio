Enkripsi Akses Kontak & Sosmed (WhatsApp, TikTok, Instagram)

Tombol WhatsApp, TikTok, dan Instagram di Manifestudio tidak pernah menampilkan nomor/username asli di kode web. Pengunjung wajib memasukkan kode akses sebelum server mengalihkan ke tujuan asli.

Panduan Setup 1 Kali di Cloudflare Pages (Binding KV)
  1. Buka Cloudflare Dashboard → Storage & Databases → KV, klik Create a namespace, beri nama manifestudio-store-vault.
  2. Buka proyek Workers & Pages → infokatalogtmctomystudio → Settings → Bindings → Add → KV namespace.
  3. Isi Variable name persis: STORE_ACCESS_KV, pilih namespace tadi, lalu klik Save (otomatis aktif pada deploy berikutnya atau klik Retry Deployment).
